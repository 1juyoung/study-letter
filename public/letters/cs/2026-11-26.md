## 개념

자바스크립트는 일꾼이 하나뿐인 싱글 스레드 언어이지만, 동시에 여러 일을 처리할 수 있는 논 블로킹 언어예요. 마치 레스토랑에서 주문을 받는 직원이 한 명뿐인데, 손님이 요리가 나올 때까지 멍하니 기다리지 않고 다음 손님 주문을 먼저 받는 것과 같아요. 이렇게 기다리지 않고 다른 일을 먼저 처리하는 방식을 비동기 처리라고 해요. 스레드는 프로그램 안에서 일 처리를 하는 하나의 흐름 단위를 뜻해요.

**핵심 정리**

- 자바스크립트는 한 번에 하나의 작업만 처리할 수 있는 싱글 스레드 언어예요.
- 동시에 여러 작업을 멈춤 없이 처리할 수 있는 논 블로킹 방식을 사용해요.
- 작업이 끝날 때까지 기다리지 않고 다음 코드를 먼저 실행하는 비동기 처리를 지원해요.
- 멀티 스레드가 아닌 이유는 여러 스레드가 같은 자원에 접근할 때 발생하는 동시성 문제를 피하기 위해서예요.

## 면접 질문

**Q.** 자바스크립트의 주요 특징과 싱글 스레드 기반에서 비동기 처리가 가능한 이유를 설명해 주세요.

**모범 답변**

자바스크립트는 싱글 스레드이면서 논 블로킹 언어입니다. 스레드가 하나뿐이라 한 번에 하나의 작업만 수행할 수 있지만, 비동기 처리를 통해 하나의 요청이 완료될 때까지 멈춰 있지 않고 동시에 다른 작업을 수행할 수 있습니다. 멀티 스레드를 사용하지 않는 이유는 동시에 공유된 자원에 접근할 때 생기는 동시성 문제를 해결하기가 까다롭기 때문입니다. 따라서 자바스크립트는 싱글 스레드의 한계를 비동기 처리로 극복하여 효율적으로 동작합니다.

## 꼬리 질문

- **Q.** 멀티 스레드 대신 싱글 스레드를 선택했을 때의 장점과 단점은 무엇인가요?
  - 장점은 동시성 문제 등 복잡한 이슈를 피할 수 있다는 점이고, 단점은 하나의 무거운 작업이 전체 흐름에 영향을 줄 수 있다는 점을 이야기해 주세요.
- **Q.** 논 블로킹과 비동기 처리는 어떤 관계가 있나요?
  - 자바스크립트는 비동기 처리를 활용하여 싱글 스레드 환경에서도 블로킹되지 않고 동시에 다른 작업을 수행할 수 있다고 설명해 주세요.

## 필기 대비 확인 문제

**1. 자바스크립트의 특징에 대한 설명으로 옳은 것을 모두 고르세요.**

① 멀티 스레드를 기본으로 사용하여 동시성 문제를 해결한다.  
② 싱글 스레드 언어이지만 비동기 처리를 통해 논 블로킹 방식으로 동작한다.  
③ 특정 로직의 실행이 끝날 때까지 다음 코드를 실행하지 않는 블로킹 방식을 강제한다.  
④ 스레드가 여러 개 존재하여 한 번에 여러 작업을 동시에 수행한다.  

> 정답: ②. 자바스크립트는 스레드가 하나뿐인 싱글 스레드 언어이지만, 비동기 처리를 통해 하나의 요청이 끝날 때까지 기다리지 않고 논 블로킹으로 동작해요. 멀티 스레드가 아닌 이유는 동시성 문제를 피하기 위해서랍니다.
