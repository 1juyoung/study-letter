## 개념

배열은 데이터를 순서대로 차곡차곡 나열해 둔 자료구조예요. 도서관 책꽂이에 책이 번호순으로 꽂혀 있는 모습과 비슷하답니다. 원하는 데이터가 어디 있는지 알면 곧바로 찾아갈 수 있어서 편리해요.

**핵심 정리**

- 배열을 회전할 때는 임시 변수를 두거나 최대공약수를 이용하는 저글링 알고리즘, 구간을 나누는 역전 알고리즘을 쓸 수 있어요.
- 배열의 특정 최대 합을 구할 때는 이전 회전 결과와의 차이 규칙을 이용해 효율적으로 계산해요.
- 주어진 배열을 arr[i] = i 형태로 재배열할 때는 값이 일치하지 않거나 -1이 아닌 경우를 조건으로 두고 값을 서로 바꿔가며 제자리를 찾아줘요.

## 면접 질문

**Q.** 배열을 왼쪽으로 회전시키는 여러 알고리즘 중 역전 알고리즘의 동작 방식을 설명해 주세요.

**모범 답변**

역전 알고리즘은 회전시키는 크기에 따라 배열의 구간을 나눈 뒤 각각을 역전시키고 전체를 다시 역전시켜 회전을 완성하는 방법입니다. 예를 들어 d만큼 회전시킨다면 처음 0부터 d-1까지의 구간과 d부터 n-1까지의 구간을 각각 뒤집습니다. 그 후 합쳐진 전체 배열을 한 번 더 뒤집으면 원하는 대로 왼쪽으로 회전된 배열을 얻을 수 있습니다. 이 과정은 swap 함수를 활용하여 효율적으로 구현할 수 있습니다.

## 꼬리 질문

- **Q.** 저글링 알고리즘은 어떤 원리로 배열을 회전하나요?
  - 최대공약수(gcd)를 이용해 전체 집합을 여러 개의 작은 그룹으로 나누어 요소를 한꺼번에 이동시키는 원리라고 설명해요.
- **Q.** 배열의 회전 과정에서 임시 변수(temp)를 사용하는 기본적인 방법의 단점은 무엇인가요?
  - 원소를 한 칸씩 이동시키는 연산을 원하는 회전 수만큼 반복해야 하므로 데이터가 많을 때 시간이 오래 걸릴 수 있다고 말해요.

## 필기 대비 확인 문제

**1. 배열을 회전시키는 역전 알고리즘에서 d만큼 왼쪽으로 회전하기 위해 가장 먼저 수행하는 작업은 무엇인가요?**

```
void rotateLeft(int arr[], int d, int n){
    reverseArr(arr, 0, d-1);
    reverseArr(arr, d, n-1);
    reverseArr(arr, 0, n-1);
}
```

① 전체 배열을 역전시킨다.  
② 첫 번째 구간인 0부터 d-1까지를 역전시킨다.  
③ 두 번째 구간인 d부터 n-1까지를 역전시킨다.  
④ 최대공약수를 구한다.  

> 정답: ②. 역전 알고리즘 구현 코드를 보면 회전 수 d를 기준으로 첫 번째 구간인 0부터 d-1까지를 먼저 역전시키는 함수(reverseArr)를 호출해요.
